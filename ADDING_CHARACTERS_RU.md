# Как добавлять новых персонажей в Character Archive

После переработки хаба новый персонаж добавляется без копирования большой карточки в корневой `index.html`. Структура, счётчик и число колонок формируются автоматически.

## 1. Подготовь папку

Создай папку с коротким именем на английском:

```text
characters/frieren/
```

Внутри придерживайся одной структуры:

```text
frieren/
├── index.html
├── styles-base.css
├── styles.css
├── script.js
└── assets/images/
    ├── main_photo.webp
    ├── background.webp
    ├── photo_1.webp
    └── ...
```

- `main_photo` — широкий фон первого экрана и карточки хаба;
- `background` — персонаж на прозрачном фоне;
- `photo_*` — плавающие кадры, галерея и About.

## 2. Сначала закончи страницу персонажа

Работай в таком порядке:

1. Замени `title`, description и theme-color.
2. Замени все тексты и About.
3. Укажи правильные пути к изображениям.
4. Подбери палитру в `:root` файла `styles.css`.
5. Настрой основную композицию.
6. Только затем расставляй плавающие изображения.
7. В конце заполни галерею и alt-подписи.

Почему так: если сразу полировать анимацию, а затем менять главный портрет, композицию придётся собирать заново.

## 3. Добавь объект в archive-data.js

Открой корневой `archive-data.js`, скопируй последний объект и поменяй поля.

```js
{
  slug: "frieren",
  number: "04",
  universe: "Frieren: Beyond Journey's End",
  firstName: "Frieren",
  lastName: "The Mage",
  description: "A quiet journey through memory and time.",
  href: "characters/frieren/index.html",
  scene: "characters/frieren/assets/images/main_photo.webp",
  figure: "characters/frieren/assets/images/background.webp",
  accent: "#8fb8d8",
  accentSoft: "#e8f4ff",
  scenePosition: "center",
  figurePosition: "bottom right"
}
```

Не забудь запятую между соседними объектами.

### Что означает каждое поле

- `slug` — уникальное техническое имя; используй строчные латинские буквы.
- `number` — номер файла в коллекции.
- `universe` — произведение или тип архива.
- `firstName` — крупная строка на карточке.
- `lastName` — маленькая строка под ней.
- `description` — короткая мысль, лучше одно-два предложения.
- `href` — путь к странице.
- `scene` — широкая фоновая фотография.
- `figure` — прозрачная фигура поверх фона.
- `accent` — линия, фокус и мягкое свечение.
- `accentSoft` — имя и второстепенные акценты.
- `scenePosition` — кадрирование фоновой фотографии.
- `figurePosition` — положение прозрачной фигуры внутри её области.

## 4. Как выбрать цвета

Не начинай с любимого цвета персонажа. Сначала изучи сами изображения:

1. Выбери самый частый тёмный оттенок для фона.
2. Найди один яркий цвет, который повторяется на важных кадрах.
3. Добавь светлый оттенок для текста и бликов.
4. При необходимости добавь один контрастный цвет, но используй его редко.

Проверь читаемость имени и кнопок на самых светлых и самых тёмных участках фотографии.

## 5. Как не сделать архив копией предыдущего

Для каждого нового героя измени минимум три пункта из списка:

- шрифт заголовков;
- расположение имени;
- принцип расстановки плавающих фотографий;
- форма скруглений;
- ритм и высота галереи;
- направление градиентов;
- композиция About;
- скорость и характер анимации.

Одна новая палитра без изменения композиции всё ещё выглядит как копия.

## 6. Как работает масштабирование хаба

`script.js` читает массив персонажей, создаёт карточки из HTML-шаблона и считает их количество.

Количество колонок выбирается по ширине экрана:

- телефон — одна;
- планшет — две;
- обычный компьютер — до трёх;
- ультраширокий монитор — до четырёх.

Если персонажей больше, карточки автоматически переходят на следующую строку. Изменять CSS при каждом добавлении не нужно.

## 7. Финальная проверка

Перед коммитом проверь:

- карточка появилась в хабе;
- счётчик увеличился;
- обе ссылки Archive работают;
- нет пустых `src`;
- все изображения открываются;
- имя не обрезается на телефоне;
- About закрывается по Escape;
- обе строки галереи движутся в разные стороны;
- при reduced motion движение отключается;
- в консоли браузера нет ошибок.

## Контрольные вопросы

1. Почему данные персонажа теперь находятся отдельно от HTML хаба?
2. Чем `scene` отличается от `figure`?
3. Почему для нового архива недостаточно изменить только цвета?
4. Что произойдёт после добавления пятого персонажа на ультрашироком экране?
5. Где исправлять кадрирование карточки, не меняя исходную фотографию?

<details>
<summary>Ответы</summary>

1. Чтобы добавлять карточки одним объектом и не дублировать разметку.
2. Scene заполняет фон с возможной обрезкой, figure показывает прозрачного персонажа отдельным слоем.
3. Композиция, типографика и ритм останутся прежними, поэтому страницы будут восприниматься как копии.
4. Первые четыре карточки останутся в первой строке, пятая начнёт следующую.
5. В поле `scenePosition` объекта внутри `archive-data.js`.
